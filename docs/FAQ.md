### Can I install EvMem on its own?

Not yet. It currently ships inside the EvAgent package and has no standalone distribution.

### Where is my data stored?

Locally. The service listens on 127.0.0.1 and reads configuration from a local file. No hosted instance is offered.

### Does it compress my memories?

No. Raw information is preserved so later processing can decide what representation is actually useful.

### Is my data private?

It stays on your machine. No security or privacy certification is claimed â€” see the limits above.

### Why is my config file sensitive?

It holds an API key and a model base URL. Never commit it or include it in a screenshot.
